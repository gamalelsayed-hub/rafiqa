# رفيقة

تطبيق موبايل للمرأة المسلمة، معمول بـ Expo (React Native). شوفي الوصف الكامل في [PROMPT.md](PROMPT.md).

## تجربته على موبايلك
1. نزّلي تطبيق **Expo Go** من Google Play أو App Store.
2. على الكمبيوتر، بعد ما تثبتي Node.js:
   ```bash
   npm install
   npx expo start
   ```
3. صوّري الـ QR code اللي هيظهر بتطبيق Expo Go (على الآيفون صوّريه بالكاميرا).

ملحوظة: التنبيهات المجدولة شغالة في Expo Go، لكن عشان تتأكدي منها بشكل كامل، اعملي نسخة APK.

## نسخة APK للأندرويد
```bash
npx eas-cli@latest build -p android --profile preview
```
(محتاجة حساب مجاني على expo.dev)

## المحتوى («الكتب»)
كل المحتوى في ملفات منفصلة في فولدر `content/`، والكود ما فيهوش أي محتوى:

| الملف | المحتوى |
|---|---|
| `content/fiqh.json` | الأحكام الفقهية |
| `content/seerah.json` | السير (قدوتي) |
| `content/status.json` | مكانة المرأة والرد على الشبهات |
| `content/parenting.json` | التربية والبر والميراث |
| `content/life.json` | مراحل حياة المرأة |
| `content/pregnancy.json` | الحمل والكشوفات وما بعد الولادة |
| `content/cycle.json` | الدورة والطهر والصحة والتهدئة |
| `content/fitness.json` | التمارين والبرامج والشرح |
| `content/library.json` | الكتب والمراجع ومنهج التطبيق |

**التطبيق بيتعامل مع الملفات دي كده:**
- أول ما يتفتح، بيقرا آخر نسخة محفوظة على الموبايل.
- في الخلفية، بيشوف لو فيه نسخة أحدث على GitHub، فينزّلها ويحفظها.
- لو مفيش نت في أول تشغيل، بيستخدم النسخة اللي جاية معاه.

**عشان تضيفي أو تعدّلي محتوى:**
1. عدّلي ملف JSON.
2. شغّلي `node scripts/build-manifest.mjs`.
3. ارفعي التعديل.

التطبيقات المتثبتة هتاخد التحديث لوحدها، من غير APK جديد. ده بيشتغل لما المستودع يكون عام (Public)، أو لما رابط `CONTENT_URL` في `src/packs.js` يشاور على مكان عام.

## نسخة APK
أي رفع على `main` بيبني APK أوتوماتيك، وبيحطه في صفحة Releases على GitHub.
